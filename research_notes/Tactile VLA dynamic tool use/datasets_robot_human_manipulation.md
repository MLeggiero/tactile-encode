# Verified dataset catalog: robot + human manipulation data with force / tactile / vibration / contact-audio (tool use, impacts, screw threading prioritized)

Verified 2026-09-28 by opening each dataset page, repo README, HF/Zenodo card or arXiv paper (v-numbers noted). "Not stated" = the page/paper I opened does not give the value. Everything marked **[IMPACT]**, **[POWER TOOL]**, **[SCREW]**, **[HAMMER]** is a highest-priority flag for the project. **[>200 Hz]** marks any channel above 200 Hz.

Mapping key for the last column: (a) pretrain tactile/force/vibration encoders; (b) engagement/impact/slip classifiers from real signatures; (c) human anticipatory grip-force priors during tool use; (d) VLA fine-tuning demos of tool tasks; (e) tool meshes/assets for simulation.

## 2. Per-dataset verified details

### 2.1 Screw / thread-engagement signal datasets (highest priority)

**pyscrew — "A comprehensive dataset collection from industrial screw driving"** — 2025, N. West & J. Deuse (TU Dortmund / RIF). arXiv 2505.11925. Six datasets, ">34,000 individual screw driving operations" on plastic components; scenarios cover thread degradation, surface-friction variation, assembly faults (up to 27 error types), fabrication-parameter changes. Signals: screw-driving process curves (torque/angle/time — sample rate not stated on abs page). Raw data on Zenodo with DOI + `PyScrew` Python loader. License CC BY 4.0. Human/robot: industrial automatic screwdriving station (no robot arm). Maps to (b): the only large corpus of real screw-engagement/fault torque signatures found. Flags: [SCREW][POWER TOOL].

**AURSAD — Universal Robot Screwdriving Anomaly Detection Dataset** — 2021, Aarhus University (ECE). arXiv 2102.01409v2; Zenodo https://zenodo.org/record/4487073. UR3e + OnRobot Screwdriver. 134 features sampled at **100 Hz** (subsampled to 50 Hz in the paper): joint positions/velocities/accelerations/currents, TCP pose/speed/forces, "screwdriver achieved torque, current torque, target torque", I/O. 2,045 runs: normal 1,420 (70%), missing screw 218, damaged screw thread 221, extra assembly component 183, damaged plate thread 3. License on arXiv: perpetual non-exclusive (dataset license on Zenodo not re-checked). Maps to (b). Flags: [SCREW][POWER TOOL].

**Kinematic and dynamic data from a robotic assembly of aeronautical threaded fasteners** — 2023, HRI² Lab (IIT Genoa) + Univ. of São Paulo (PMC10630597). KUKA KR-16 with ATI Delta SI-660-60 wrist F/T; 18 channels + time (position, orientation, force, torque, linear/angular velocity) recorded every 12 ms (~83 Hz), 2,560 steps (~31 s) per trial. 479 trials: 306 mounted, 112 not mounted, **61 jammed**. Phases: translational alignment, rotational fitting (backspin), screwing. Mendeley Data https://data.mendeley.com/datasets/26674p3hvg/1, CC BY 4.0. Maps to (b) thread-engagement / jam classifier. Flag [SCREW].

**REASSEMBLE** — 2025, TU Wien Autonomous Systems Lab. arXiv 2502.05086 (v2 Apr 2025); page https://tuwien-asl.github.io/REASSEMBLE_page/; data https://researchdata.tuwien.ac.at/records/0ewrv-8cb44 (v1.0.0, 25 Apr 2025; data.zip 54.8 GiB; CC BY 4.0; code MIT). Franka FR3; AIDIN ROBOTICS AFT200-D80-C 6-axis wrist F/T (measured + gravity-compensated); DAVIS346 event camera (33 ms accumulation for visualization); 2× HAMA C-600 Pro + wrist RealSense D435i RGB (30 fps, 10 fps used); 3 microphones incl. OSA K1T wireless mic on gripper (MP3 in HDF5); joint pos/vel/effort (7), gripper width. **Sample rates: "native publishing frequency" — no Hz values on paper, page, README or data record.** 4,551 demos (4,035 successful), 781 min. 17 objects: Ethernet/USB/waterproof/BNC/D-SUB connectors, 3 gears, **1 M16 nut**, 4 round pegs (4/8/12/16 mm), 4 square pegs. Actions pick/insert/remove/place + 9 low-level skills incl. **"Twist ... used when rotating a BNC connector or nut"** (nut screwing with regrasps). Maps to (b) nut-threading F/T + audio signatures, (d) demos. Flag [SCREW].

**RH20T** — arXiv 2307.00595v2 (Sept 2023), ICRA 2024, Shanghai Jiao Tong University; https://rh20t.github.io/; API https://github.com/rh20t/rh20t_api. Configs: cfg1 Flexiv+Dahuan AG95+OptoForce; cfg2 Flexiv+ATI Axia80-M20; cfg3/4 UR5+ATI Axia80-M20 (Robotiq-85 on cfg4); cfg5 Franka (internal F/T); cfg6/7 KUKA+Robotiq-85+ATI Axia80-M20, **cfg7 adds uSkin fingertip tactile (2x16x3 @ 200 Hz)**. Table of modalities (paper Tab. III): RGB/depth/IR 1280x720 @ 10 Hz; joint angle 10 Hz; joint torque 10 Hz; gripper Cartesian pose 100 Hz; gripper width 10 Hz; **6-DoF F/T 100 Hz; audio "30 Hz" (as printed); tactile 200 Hz**. 110k+ robot sequences + equal number of human demonstration videos, 147 tasks (48 RLBench, 29 MetaWorld, 70 self-proposed), >50 M images. Task-table entries I could extract that touch this project: "15. Play the drum" (self-proposed), "16. Hit the pool ball into ...", "42. Screw the lid onto the jar", "43. Unscrew the lid from the jar", "111. Put the object with the corresponding shape into the corresponding hole", "112. Plug in ... the socket", "120. Install the light bulb by rotating it", "126–130 Plug in the power cord / bulb holder", "200–202 Insert pipette tips". The word "hammer" does not occur anywhere in the extracted PDF text; no drill/screwdriver/wrench task found. License CC BY-SA 4.0 (RH20T-C, scenes 0001–0005) and CC BY-NC 4.0 (RH20T-NC, scenes 0006–0010). Maps to (a) large F/T+audio corpus for pretraining, (d) contact-rich demos, (b) weak (jar-lid screwing, drum/pool impacts).

**Kaiwu** — RA-L 2025, arXiv 2503.05231 (HTML). Human assembly of a robot-arm kit ("front arm, end arm ... flange bearings, linkage, motor ... bolts, nuts, power cable") using **drill, snips, file, polisher, vernier calipers, sharp-nosed pliers, screwdriver**. 20 subjects, 30 objects, 11,664 action instances. Sensors: data glove with 19 pressure + 19 angle sensors ("sensing accuracy of 9 g") at **100 Hz**; Trigno EMG + 9-DoF IMU at 40 Hz; 4 microphones (paper says 50 Hz — likely a feature rate, not audio sample rate); optical mocap 37 markers 60 Hz; binocular eye tracker 25 Hz; RGB-D 60 fps. Data on ScienceDB (DOI; annotation 31.84 GB, raw 167 GB) — the ScienceDB page is JS-rendered so **license not verified**. Maps to (c) human grip pressure during power-drill/screwdriver use (unique among human sets). Flags [POWER TOOL][SCREW].

### 2.2 Impact / vibration / contact-audio datasets

**RealImpact** — CVPR 2023, Stanford (Clarke, Gao, Wang et al.); arXiv 2306.09944; https://samuelpclarke.com/realimpact/; code https://github.com/samuel-clarke/RealImpact (MIT). "150,000 recordings of impact sounds of 50 everyday objects" with impact locations, 600 microphone locations (15 mics; 10 azimuths × 4 distances), **contact force profiles from an impact hammer**, material labels, RGB-D. Hammer model / force and audio sample rates not stated on the page or repo README (repo has `hardware/` designs for the "hammer striking mechanisms"). Preprocessed data via `dataset/download.sh`; raw data "being packaged". Tools among objects: not stated. Maps to (a)(b) impact acoustics + force. Flag [IMPACT].

**ObjectFolder Real (ObjectFolder Benchmark)** — CVPR 2023, Stanford SVL; arXiv 2306.00956; download page https://objectfolder.stanford.edu/objectfolder-real-download; repo https://github.com/rhgao/ObjectFolder (CC BY 4.0). 100 real household objects (ceramic, glass, wood, steel, iron, plastic, polycarbonate). Audio: "PCB22 impact hammer (086C01)" with force transducer + PCB 376A32 free-field mic in anechoic chamber, 30–50 strike points/object, 5–6 s clips (sample rate not stated). Touch: Franka Panda + GelSight R1.5 finger (32x24 mm²) at same points (fps not stated). Meshes at ~16k / ~64k / full res. **Inventory includes wrenches (small/middle/large), pestle, mortar, ladle, spatulas, pasta server, skimmers, trim-removal tools.** Maps to (a)(b) impact+touch encoders, (e) wrench meshes. Flag [IMPACT].

**SonicBoom** — arXiv 2412.09878 (Dec 2024), CMU RI; page https://iamlab-cmu.github.io/sonicboom/; code https://github.com/markmlee/vibrotactile_localization.
